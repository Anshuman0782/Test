# Number Sorter Repository README.md
=====================================

## Project Overview
-----------------

This is a simple web-based number sorting application.

## Tech Stack
------------

* HTML 5
* CSS 3
* JavaScript

## Features
------------

* Input field for entering numbers separated by commas
* Two buttons for sorting numbers in ascending and descending order

## Project Structure
-------------------

The repository consists of only a single HTML file (`index.html`) without sufficient description.

## Local Setup
--------------

To run the application, simply open `index.html` in a web browser.

## Usage Flow
--------------

1. Enter numbers separated by commas in the input field.
2. Click on the "Sort Asc" or "Sort Desc" button to sort the numbers.
3. The sorted result will be displayed below the input field.
